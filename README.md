# Aster Coffee ☕

**A Warm Place for Coffee & Freshly Baked Moments.**

Aster Coffee is a modern cafe and bakery website designed to showcase a welcoming coffee experience through elegant visuals, warm branding, and an intuitive browsing experience.

## Live Website

[Visit Aster Coffee](https://aster-coffee.netlify.app/)

## Overview

Aster Coffee is Project 02 of my 30-Website Challenge, an initiative to build 30 websites while improving my frontend development, UI design, and practical implementation skills.

The website is designed for a cafe and bakery, with a focus on presenting its menu, atmosphere, story, gallery, and contact information in a polished and accessible way.

## Website Pages

The project includes five main sections:

- **Home** – Introduction to the cafe and its atmosphere.
- **Menu** – Coffee, bakery products, and menu offerings.
- **Our Story** – The brand's identity and story.
- **Gallery** – Visual presentation of the cafe and its products.
- **Contact** – Business contact information and location.

## Design Direction

The visual identity uses a warm, modern, and approachable cafe aesthetic.

### Brand Colors

| Color | Hex Code | Purpose |
|---|---|---|
| Cream | `#F7F1E7` | Main background |
| Espresso Brown | `#49352B` | Primary brand color |
| Caramel | `#B8794B` | Accent color |
| Sage Green | `#68745B` | Secondary accent |

### Typography

- Elegant serif typography for headings.
- Clean, readable sans-serif typography for body text.

## Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/belaaa27/aster-coffee.git
```

### 2. Navigate to the project directory

```bash
cd aster-coffee
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Build for production

```bash
npm run build
```
